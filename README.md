# bowling-lane-growth-system（第四弾：会員管理・成長支援システム）

スポーツボウリング場運営システムの第四弾。会員一人ひとりの「成長」を支援するための、会員管理・マイギア管理・投球データ蓄積・成長ダッシュボードを実装しています。

このリポジトリは、  
- 第一・二弾：予約システム（bowling-lane-reservation-system）  
- 第三弾：店舗運営システム（bowling-lane-management-system）  

に続くフェーズで、第三弾のスタッフ認証・チェックイン等のデータモデル設計思想を踏襲しています。

---

## 開発の位置づけ

第一・二弾：利用者向け予約システム／教室運営  
↓  
第三弾：スポーツボウリング場の店舗運営システム  
↓  
第四弾：会員管理・成長支援システム（本リポジトリ）  
↓  
第五弾：独自・高機能スコアリングシステム（bowling-lane-scoring-system、別リポジトリ）  


第五弾は独立したリポジトリとして開発しており、本リポジトリには第五弾のコードは含みません。

---

## 実装機能

- スタッフ認証（PINログイン、ロックアウト機構、管理者権限、初回PIN変更強制）
- 会員本人認証（会員コード／電話番号＋PINログイン）
- 会員管理（登録・一覧・検索）
- マイギア管理（セルフ登録／スタッフ代理登録）
- ギアメンテナンス履歴（オイル抜き等）
- チェックイン／チェックアウト（重複チェックイン防止）
- 複数人セッション対応（アメリカン方式）
- Game／Frame／Shot単位の投球データ保存（残りピンパターン含む）
- ギア⇔ゲーム紐付け（累計投球数カウント）
- 標準10フレームスコア計算ロジック
- 会員成長ダッシュボード（平均・最高・最低スコア、ストライク率、スペア率、10番ピン残り率、直近成績）

# 第三弾拡張（Phase 3 Extension）

---

## 第三弾拡張④：初心者教室修了記録

第三弾（教室運営）とは別アプリ・別DBのため自動連携せず、スタッフが手動で紐付ける。  
「初心者教室を修了し、一般ボウラーとして利用可能になった」という事実のみを管理し、  
出席回数・各回の指導内容・コーチによる適性評価は持たない。  
詳細は `docs/phase3_extension_class_completion.md` に設計メモを残している。

---

## 第三弾拡張③：レーン設定・状態管理 × 達成バッジ・称号

### ● レーン設定・レーン状態管理（LaneSettings / Lane）
- 総レーン数（total_lanes）を設定値として管理（初期値4）  
- admin が total_lanes を変更すると不足レーン番号を自動生成  
- レーン状態：`available` / `maintenance` / `broken`  
- レーン用途：`general` / `class` / `competitor`  
- チェックイン時のレーン番号は、スタッフが `GET /api/v1/lanes` で当日の空き状況を確認し、
  手動で指定する運用（4レーン運用ではスタッフが目視で十分判断できるため、自動アサインは
  現時点では採用していない。将来レーン数が大幅に増えた場合の拡張候補）

### ● 達成バッジ（AchievementBadge）
- 判定ロジックは `app/services/badge_criteria.py` に分離  
- 第四弾単体で完結する条件のみ実装  
  - 初投球  
  - 累計10ゲーム  
  - 累計100ゲーム  
  - ギア登録  
- 将来第五弾の指標を使う場合も関数追加だけで拡張可能

### ● API 一式
- GET/PATCH `/api/v1/lanes/settings`  
- GET `/api/v1/lanes`  
- PATCH `/api/v1/lanes/{lane_number}/status`  
- PATCH `/api/v1/lanes/{lane_number}/purpose`  
- POST `/api/v1/badges/evaluate/{user_id}`  
- GET `/api/v1/badges/user/{user_id}`

### ● チェックイン仕様
- `lane_number` は引き続き必須（スタッフが手動指定）

## 第三弾拡張①：オイル抜きリマインド（メンテナンス管理）

### ● リマインダー判定
- normal  
- alert（30ゲーム以上）  
- snoozed  
- disabled

### ● リマインダー操作
- disable（無効化）  
- snooze（スヌーズ）  
- reset（リセット）

### ● 権限
- 会員本人のみ操作可能  
- スタッフは閲覧のみ（操作不可）

### ● 役割
- ギアメンテナンス履歴の基盤  
- ギア状態管理（使用状況・メンテナンス状況）の統合  
- 将来の「メンテナンス通知」「ギア状態ダッシュボード」への発展が可能
