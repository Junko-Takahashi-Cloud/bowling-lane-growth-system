# bowling-lane-growth-system（第四弾：会員管理・成長支援システム）

スポーツボウリング場運営システムの第四弾。会員一人ひとりの「成長」を支援するための、会員管理・マイギア管理・投球データ蓄積・成長ダッシュボードを実装しています。

このリポジトリは、[bowling-lane-reservation-system](https://github.com/Junko-Takahashi-Cloud/bowling-lane-reservation-system)（第一・二弾：予約システム）、[bowling-lane-management-system](https://github.com/Junko-Takahashi-Cloud/bowling-lane-management-system)（第三弾：店舗運営システム）に続くフェーズで、第三弾のスタッフ認証・チェックイン等のデータモデル設計思想を踏襲しています。

## 開発の位置づけ

```
第一・二弾：利用者向け予約システム／教室運営
    ↓
第三弾：スポーツボウリング場の店舗運営システム
    ↓
第四弾：会員管理・成長支援システム（本リポジトリ）
    ↓
第五弾：独自・高機能スコアリングシステム（構想中）
```

## 実装機能

- スタッフ認証（PINログイン、ロックアウト機構、管理者権限、初回PIN変更強制）
- 会員本人認証（会員コード／電話番号＋PINログイン、なりすまし防止設計）
- 会員管理（登録・一覧・検索）
- マイギア管理（マイボール・マイシューズ、セルフ登録／スタッフ代理登録の両ルート対応）
- ギアメンテナンス履歴（オイル抜き等、累計投球数のリセット・記録）
- チェックイン／チェックアウト（同一レーンへの重複チェックイン防止）
- 複数人セッション対応（アメリカン方式など、同一レーンでの複数プレイヤー管理）
- Game／Frame／Shot単位での投球データ保存（残りピンパターン記録を含む）
- ギア⇔ゲームの紐付け（使用ギアごとの累計投球数カウント）
- 標準10フレームスコア計算ロジック
- 会員成長ダッシュボード（平均・最高・最低スコア、ストライク率、スペア率、10番ピン残り率、直近成績）

## 技術構成

- FastAPI / SQLAlchemy / SQLite
- 認証：JWT（スタッフ用・会員用トークンを型で明確に分離）
- テスト：pytest + FastAPI TestClient によるE2Eテスト（45件）

## セットアップ

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

初回起動時、管理者スタッフが1人も存在しない場合は自動生成されます（ランダムPINはサーバーログにのみ出力）。

## テスト実行

```bash
pytest tests/ -v
```
